# dartool

[![pub version](https://img.shields.io/pub/v/dartool.svg)](https://pub.dev/packages/dartool)
[![中文文档](https://img.shields.io/badge/README-中文-blue)](README.zh.md)

> A Hutool-style toolkit for Dart -- simple, unified and out-of-the-box.

`dartool` is the pure-Dart core package of the dartool project. It has zero Flutter dependencies, so it works in both Flutter apps and pure Dart CLI / server projects. Inspired by [Hutool](https://hutool.cn/), it follows the philosophy of "one method for one problem -- modular, on-demand, no bloat."

## Features

- Modular -- pick only what you need, no unnecessary dependencies
- Pure Dart -- zero Flutter dependency, usable in CLI and server projects
- Unified API -- consistent naming, friendly parameters, ready to use
- Well tested -- unit tests for every core module
- Dart 3 + null-safe -- built on Dart 3.9 SDK with `lints`

## Quick Start

```dart
import 'package:dartool/dartool.dart';

void main() {
  // String utilities
  print(StrUtil.isBlank('   '));               // true
  print(StrUtil.toCamelCase('hello_world'));   // helloWorld

  // Collection utilities
  print(CollectionUtil.isEmpty([]));            // true
  print(CollectionUtil.distinct([3, 1, 2, 1]));   // [3, 1, 2]

  // Date utilities
  print(DateUtil.formatNow());                  // 2026-09-21 12:00:00

  // Validation utilities
  print(ValidateUtil.isEmail('a@b.com'));       // true
  print(ValidateUtil.isPhone('13800138000'));   // true

  // ID generation
  print(IdUtil.uuid());                         // xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

  // Color utilities
  print(ColorUtil.toHex(0xFF4080FF));           // #4080FF
  print(ColorUtil.hexToInt('#4080ff'));         // 0xFF4080FF

  // Crypto utilities
  print(CryptoUtil.md5('hello'));               // 5d41402abc4b2a76b9719d911017c592
  print(CryptoUtil.base64Encode('hello'));      // aGVsbG8=

  // Result container
  final r = Result.success('ok');
  print(r.isSuccess);                           // true

  // Optional container
  final op = Optional.of('hello');
  print(op.getOrElse('default'));                 // hello
}
```

## API Overview

| Class | Description |
|---|---|
| `StrUtil` | String blank checks, case conversion, trimming, truncation, camel/snake conversion |
| `CollectionUtil` | Collection empty checks, dedup, pagination, flatten, grouping |
| `DateUtil` | Formatting, parsing, timestamp conversion, relative time, timezones |
| `RegexUtil` | Common regex patterns (phone, email, URL, ID card) and matchers |
| `EnumUtil` | Enum name/value resolution, iteration |
| `ValidateUtil` | Data validation (non-null, email, phone, ID card, range) |
| `ConvertUtil` | Type conversion (String <-> num <-> bool <-> DateTime) with fallbacks |
| `IdUtil` | UUID, snowflake ID, short unique ID generation |
| `ColorUtil` | Color conversion (ARGB int <-> hex), luminance, interpolation |
| `CryptoUtil` | Base64 / Hex encoding, MD5 / SHA1 / SHA256 / SHA512 hashing, HMAC, XOR obfuscation |
| `Optional` | Null-safe value container (Java Optional style) |
| `Result` | Success / failure container with data or error |
