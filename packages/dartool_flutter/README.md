# dartool_flutter

[![pub version](https://img.shields.io/pub/v/dartool_flutter.svg)](https://pub.dev/packages/dartool_flutter)

> Flutter-specific extensions for dartool.

`dartool_flutter` provides utilities that depend on Flutter SDK (platform detection, logging, etc.). Use it together with the pure-Dart `dartool` core package.

## Features

- Separate package -- pure Dart projects do not need this dependency
- Web-safe platform detection -- correctly handles Web where `dart:io` is unavailable
- Lightweight logger -- level-based filtering with tags and swappable output channel
- Dart 3 + null-safe -- built on Dart 3.9 SDK / Flutter 3.22+

## Installation

```yaml
dependencies:
  dartool: ^0.1.0-dev.1
  dartool_flutter: ^0.1.0-dev.1
```

```bash
flutter pub get
```

## Quick Start

```dart
import 'package:dartool/dartool.dart';
import 'package:dartool_flutter/dartool_flutter.dart';

void main() {
  // Platform detection (Web-safe, never throws)
  if (PlatformUtil.isAndroid) {
    LogUtil.info('running on Android');
  }
  if (PlatformUtil.isMobile) {
    LogUtil.debug('mobile device detected');
  }
  if (PlatformUtil.isDesktop) {
    LogUtil.warn('desktop platform');
  }

  // Tagged logging
  LogUtil.error('network failed', tag: 'NetworkService');

  // Customize minimum log level (e.g. suppress debug in release)
  LogUtil.minLevel = LogLevel.info;

  // Pipe logs to a custom destination
  LogUtil.output = (line) => myRemoteLogger.send(line);
}
```

## API Overview

| Class | Description |
|---|---|
| `PlatformUtil` | Platform detection (Android, iOS, Web, macOS, Windows, Linux, Mobile, Desktop) -- Web-safe |
| `LogUtil` | Leveled logging (debug, info, warn, error) with tags, level filter and swappable output |
